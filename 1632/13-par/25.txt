Y odłącżył Dawid y Hetmáni wojſká / ná poſługowánie / Syny Aſáfowe y Hemánowe / y Jedytunowe / którzy prorokowáli przy cytrách / y przy hárfách / y przy cymbalech : á byłá licżbá ich / <i>to jeſt</i> mężów prácujących w uſłudze ſwey.
Z Synów Aſáfowych / Záchur / y Józef / y Náttániaƺ / y Aſárelá : Synowie Aſáfowi <i>byli</i> pod ręką Aſáfową / który prorokował ná rozkazánie królewſkie.
Z Jedytuná : Synowie Jedytunowi / Godoliaƺ / y Zeri / y Jeſájaƺ / Háſábiaƺ / y Mátityaƺ / y <i>Symei</i> ƺeść ; pod ręką Ojcá ich Jedytuná : który prorokował przy hárfie / wyznawájąc y chwaląc PANA.
Z Hemáná ; Synowie Hemánowi : Bukkiaƺ / Mátániaƺ / Huſiel / Zebuel / y Jerimot / Chánániaƺ / Chánáni / Eliátá / Geddálty / y Romántieſer / y Jásbekáſſá / Málloty / Hotyr / Mácháziot.
Ci wƺyſcy <i>byli</i> Synowie Hemáná / Widzącego królewſkiego w ſłowiech Bożych : ku wywyżƺeniu rogu : bo dał Bóg cżternaśćie Synów Hemánowi / y trzy córki.
Ci wƺyſcy <i>byli</i> pod ſpráwą Ojcá ſwego / przy śpiewániu w domu PAńſkim / ná cymbalech / ná Lutniách / y ná Cytrách ku ſłużbie w domu Bożym / jáko rozkazał Król / <i>y</i> Aſáf / Jedytun y Hemán.
A był pocżet ich z bráćią ich / którzy byli ćwicżonymi w pieśniách PAńſkich : wƺyſtkich miſtrzów / dwie śćie ośmdźieśiąt y ośm.
Y miotáli loſy / ſtraż przećiwko ſtraży : ták máły jáko y wielki / ták miſtrz jáko y ucżeń.
Y padł los pierwƺy <i>w domu</i> Aſáfowym / ná Józefá : ná Godoliaƺá wtóry / z bráćią jego / y z Syny jego / <i>których było</i> dwánaśćie.
