A Synowie Aáronowi tym ſpoſobem rozdźieleni <i>byli</i>. Synowie Aáronowi <i>byli</i> : Nádáb / y Abiu / Eleázár / y Itámár.
Ale iż Nádáb y Abiu umárli przed oblicżem Ojcá ſwego / á Synów nie mieli : Przetoż odpráwowáli urząd kápłáńſki / Eleázár / y Itámár.
Y podźielił je Dawid / <i>to jeſt</i> Sádoká z Synów Eleázárowych / y Achimelechá / z Synów Itámárowych / według urzędu ich / w uſługách ich.
Y ználázło śię Synów Eleázárowych / więcey przedniejƺych mężów / niż Synów Itámárowych / gdy je podźielił. Z Synów Eleázárowych <i>było</i> przedniejƺych / według domów Ojcowſkich / ƺeſnaśćie : ále z Synów Itámárowych według domów Ojcowſkich ośm.
A rozdźieleni ſą loſem jedni od drugich : bo byli przełożonymi <i>nád</i> Świątnicą / y przedniejƺymi przed Bogiem / <i>ták</i> z Synów Eleázárowych / jáko y z Synów Itámárowych.
A popiſał ich Semejaƺ / Syn Nátánáelów / piſarz z <i>pokolenia</i> Lewi / przed Królem y Kśiążętámi / y <i>przed</i> Sádokiem kápłánem / y Achimelechē Synē Abiátárowym / y przedniejƺymi z domów Ojcowſkich / kápłanów y Lewitów : A náznácżono jeden dom Ojcowſki Eleázárowi ; á drugi náznácżono Itámárowi.
Y padł los pierwƺy ná Jehojárybá : ná Jedájaƺá wtóry.
Ná Hárymá trzeći : ná Seorymá cżwárty.
Ná Málchiaƺá piąty : ná Mijámáná ƺóſty.
Ná Akkoſá śiódmy : ná Abiaƺá óſmy.
Ná Jeſuego dźiewiąty : ná Secheniaƺá dźieśiąty.
Ná Eliáſibá jedenaſty : ná Jákimá dwánaſty.
Ná Huppá trzynaſty : ná Jeſebábá cżternaſty.
Ná Bilgę piętnaſty : ná Immerá ƺeſnaſty.
Ná Chezyrá śiedmnaſty : ná Háppiſeſá ośmnaſty.
Ná Petáchiaƺá dźiewiętnaſty : ná Ezechielá dwudźieſty.
Ná Jáchiná dwudźieſty y pierwƺy : ná Gámuelá dwudźieſty y wtóry.
Ná Delájaƺá dwudźieſty y trzeći : ná Mááziaƺá dwudźieſty y cżwarty.
Cić <i>ſą</i> ſporządzeni w poſługowániu ſwojim / áby wchodźili do domu PAńſkiego w przemiánách ſwych <i>jáko zwykli</i> pod rządem Aároná Ojcá ich / jáko mu był rozkazał PAN Bóg Izráelſki.
A z Synów Lewiego którzy byli pozoſtáli z Synów Amrámowych Subáel : z Synów Subáelowych Jechdejaƺ.
Z Rechábiaƺá / z Synów Rechábiaƺowych / <i>był</i> przedniejƺy / Jeſyaƺ.
Z Iſááry / Sálomit : z Synów Sálomitowych Jáchát.
A Synowie Jeryaƺowi / Amáryaƺ wtóry : Jeháziel trzeći : Jekmáán cżwarty.
Synowie Huſielowi Michá : z Synów Michy / Sámir.
Brát Micháſów / Jeſyaƺ : z Synów Jeſyaƺowych / Zácháryaƺ.
Synowie Merárego : Máheli / y Muſy : Synowie Jáháſiaƺowi Beno.
Synowie Merárego z Jáháſiaƺá / Beno / y Soám / y Záchur / y Hibri.
Z Máhálego / Eleázár : który nie <i>miał</i> Synów.
Z Cyſá : Synowie Cyſowi Jeráhmeel.
A Synowie Muſy Máheli / y Eder / y Jerimot. Cić <i>byli</i> Synowie Lewitów / według domów Ojców ich.
Y ći też miotáli loſy náprzećiwko bráćij ſwojey / Synom Aáronowym / przed Dawidem Królem / y Sádokiem / y Achimelechem / y przedniejƺymi <i>domów</i> Ojcowſkich / z Kápłanów y Lewitów / z <i>domów</i> Ojcowſkich : káżdy przedniejƺy przećiwko brátu ſwemu młodƺemu.
