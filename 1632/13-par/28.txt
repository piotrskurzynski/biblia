Tedy zgromádźił Dawid wƺyſtkie Kśiążętá Izráelſkie / y przedniejƺe <i>z káżdego</i> pokolenia / y przełożone nád hufcámi / które ſłużyły królowi / y półkowniki / y rotmiſtrze / y przełożone nád wƺyſtką májętnośćią / y ośiádłośćią królewſką : Syny też ſwoje / z komornikámi / y z innymi możnymi / y ze wƺyſtkim ludem rycerſkim / do Jeruzalem.
A powſtawƺy Król Dawid ná nogi ſwoje / rzekł ; Słuchajćie mię bráćia moji / y ludu mój. Jam był umyślił w ſercu ſwym budowáć dom / gdźieby odpocżywáłá ſkrzyniá przymierza PAńſkiego / y ná podnóżek nóg Bogá náƺego / y zgotowałem był <i>potrzeby</i> ku budowániu.
Ale Bóg rzekł do mnie : Nie będźieƺ budował domu Imieniowi memu / przeto żeś mąż walecżny / y rozlewałeś krew.
Ale obrał mię PAN Bóg Izráelſki ze wƺyſtkiego domu Ojcá mego / ábym był Królem nád Izráelem ná wieki : bo z Judy obrał Kśiążę / á z narodu Judſkiego dom Ojcá mego : y z Synów Ojcá mego upodobał mię ſobie zá Królá nád wƺyſtkim Izráelem.
A ze wƺyſtkich Synów mojich ( bo mi wiele Synów PAN dał ) obrał Sálomoná Syná mego / áby śiedźiał ná ſtolicey króleſtwá PAńſkiego nád Izráelem.
Y mówił do mnie : Sálomon Syn twój / ten zbuduje dom mój / y przyśionki moje : ábowiemem go ſobie obrał zá Syná / á JA mu będę zá Ojcá.
Y umocnię króleſtwo jego áż ná wieki / będźieli ſtátecżnym w pełnieniu przykazań mojich / y ſądów mojich jáko y dźiś.
Teraz tedy mówię wam przed oblicżem wƺyſtkiego Izráelá / zgromádzenia <i>tego</i> PAńſkiego / gdźie ſłyƺy Bóg náƺ : ſtrzeżćie á ƺukajćie wƺyſtkich rozkazań PANA Bogá wáƺego / ábyśćie ośiedli źiemię dobrą / y zoſtáwili ją w dźiedźictwo ſynom ſwoim po ſobie / áż ná wieki.
A ty Sálomonie Synu mój / znaj Bogá Ojcá twojego / y ſłuż mu ſercem doſkonáłym / y umyſłem dobrowolnym : bo wƺyſtkie ſercá przegląda PAN / y wƺyſtkie zamyſły myśli zna. Jeſli go ƺukáć będźieƺ / znajdźieƺ go : á jeſli go opuśćiƺ / odrzući ćię ná wieki.
Obacżże teraz / iż ćię PAN obrał / ábyś zbudował dom świątnice : zmacniajże śię / á wykonaj <i>to</i>.
Tedy oddał Dawid Sálomonowi Synowi ſwemu wizerunek przyśionku / y gmáchów jego / y komor jego / y ſal jego / y wnętrznych pokojów jego / y domu ubłagálni.
Przytym wizerunek wƺyſtkiego co był umyślił / o śieni domu PAńſkiego / y o wƺyſtkich gmáchách dla ſkárbów domu Bożego / y dla ſkárbów rzecży świętych.
Y dla pocżtów Kápłáńſkich / y Lewitów / y dla wƺyſtkiey prace w uſłudze domu PAńſkiego / y dla wƺyſtkiego nacżynia ſłużby domu PAńſkiego.
Tákże złotá pewną wágę / ná wƺyſtkie nacżynia złote / od wƺyſtkiey uſługi : śrebrá tákże ná wƺyſtkie nacżynia śrebrne / pewną wagę / ná wƺyſtkie nacżynia ku wƺelákiey uſłudze.
Miánowićie <i>pewną</i> wagę : ná świecżniki złote / y ná lámpy ich złote według wagi káżdego świecżniká / y lámp jego : y ná świecżniki śrebrne / według wagi świecżniká <i>káżdego</i> y lámp jego / według potrzeby káżdego świecżniká.
Tákże pewną wagę złotá / ná ſtoły chlebów pokłádnych / ná káżdy ſtół : przytym śrebrá ná ſtoły śrebrne.
A ná widełki y ná koćiełki / y ná kádźielnicę ƺcżerego złotá / y ná cżáƺe złote / pewną wágę ná káżdą cżáƺę : y ná cżáƺe śrebrne / <i>pewną</i> wagę ná káżdą cżáƺę.
Tákże ná Ołtarz do kádzenia dał złotá ƺcżerego <i>pewną</i> wagę / y złotá ku wyſtáwieniu wozá Cherubinów / którzyby rozćiągnionymi ſkrzydłámi okrywáli ſkrzynię przymierza PAńſkiego.
To wƺyſtko <i>( rzekł Dawid )</i> opiſáne z ręki PAńſkiey mię doƺło / ábym zrozumiał wƺyſtko / jáko co urobić miano.
A ták rzekł Dawid do Sálomoná Syná ſwego : Zmácniaj śię á bądź mężnym / cżyń to ; nie bój śię / áni śię lękaj : bo PAN Bóg / Bóg mój <i>będźie</i> z tobą : nie opuśći ćię / áni ćię odſtąpi / áż dokońcżyƺ wƺyſtkiey roboty ſłużby domu PAńſkiego.
A oto pocżty Kápłanów y Lewitów do káżdey poſługi w domu Bożym / <i>będą</i> z tobą w káżdey pracy : káżdy ochotny y roſtropny przy wƺelkiey poſłudze / tákże Kśiążętá / y wƺyſtek lud <i>ſtáną</i> ná káżde rozkazánie twoje.
