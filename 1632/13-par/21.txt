Ale Szátán powſtał przećiw Izráelowi / á pobudźił Dawidá / áby policżył Izráelá.
Przetoż rzekł Dawid do Joábá / y do przełożonych nád ludem : Idźćie / oblicżćie Izráelá od Beerſebá / áż do Dán : á odnieśćie do mnie / żebym wiedźiał pocżet ich.
Ale rzekł Joáb. Niech przymnoży PAN ludu ſwego / jáko teraz jeſt / tyle ſto kroć : yzali Królu Pánie mój / nie ſą wƺyſcy oni ſługámi Páná mego? przecżże śię tego dowiáduje Pán mój? przecżżeby to miáło być ná upadek Izráelowi?
Wƺákże ſłowo królewſkie przemogło Joábá : przetoż wyƺedł Joáb / á obƺedƺy wƺyſtkiego Izráelá / wróćił śię potym do Jeruzalem.
Y oddał Joáb pocżet poráchowánego ludu Dawidowi : á było wƺyſtkiego Izráelá tyśiąc tyśięcy / y ſto tyśięcy mężów godnych ku bojowi : á z Judy było cżtery kroć ſto tyśięcy / y śiedmdźieśiąt tyśięcy mężów walecżnych.
Lecż Lewitów y Benjámitów / nie policżył miedzy nie ; gdyż przykre było rozkazánie królewſkie Joábowi.
Owƺem nie podobáłá śię Bogu tá rzecż / przetoż pokarał Izráelá.
Y rzekł Dawid do Bogá : Zgrzeƺyłem bárzo / żem to ucżynił : ále teraz oddal / proƺę / niepráwość ſługi twego / bom bárzo głupie ucżynił.
Zátym rzekł PAN do Gádá Proroká Dawidowego mówiąc ;
Idź / powiedz Dawidowi / á rzecż ; Ták mówi PAN : Trzyć rzecży podawam ; obierz ſobie jednę z nich / ábymći ucżynił.
Tedy przyƺedł Gád do Dawidá / y rzekł mu : Ták mówi PAN ; Obierz ſobie :
Albo przez trzy látá głód : álbo żebyś przez trzy mieśiące ginął od nieprzyjaćiół twych / á miecż nieprzyjaćiół twojich żeby ćię śćigał : álbo żeby przez trzy dni miecż PAńſki / y mor <i>był</i> w źiemi / á Anjoł PAńſki żeby niƺcżył wƺyſtkie gránice Izráelſkie? Przetoż teraz uważ co mam odpowiedźieć temu który mię poſłał.
Y rzekł Dawid do Gádá : Bárzom zćiśniony ; niech wpádnę / proƺę / w ręce PAńſkie / gdyż bárzo wielkie ſą zlitowánia jego / á w ręce ludzkie niechaj nie wpadam.
Tedy przepuśćił PAN powietrze morowe ná Izráelá : Y poległo z Izráelá śiedmdźieśiąt tyśięcy mężów.
Poſłał też Bóg Anjołá do Jeruzalem / áby je tráćił : á gdy je tráćił / ujrzał PAN / y użalił śię nád tym złym : y rzekł Anjołowi trácącemu : Doſyć ; już záwśćiągni rękę twą. A Anjoł PAńſki ſtał podle bojewiſká Ornáná Jebuzejcżyká.
W tym podnióżƺy Dawid ocży ſwe / ujrzał Anjołá PAńſkiego / który ſtał miedzy źiemią y miedzy niebem : á w ręce jego miecż jego dobyty wyćiągniony przećiw Jeruzalem. Y upadł Dawid / y ſtárƺy oblekƺy śię w wory ná twarzy ſwoje :
Zátym rzekł Dawid do Bogá : Izalim nie ja rozkazał licżyć ludu? Jamći jeſt ſam którym zgrzeƺył / y bárzo źle ucżynił : ále te owce cóż ucżyniły? PANIE Boże mój / niech śię obróći / proƺę / ręká twojá ná mię y ná dom Ojcá me° : ále przećiwko ludowi twemu niech śię nie ſroży tá plagá.
Zátym Anjoł PAńſki rzekł do Gádá / áby mówił Dawidowi / żeby ƺedł y zbudował Ołtarz PANU / ná bojewiſku Ornáná Jebuzejcżyká.
A ták ƺedł Dawid według ſłowá Gádowego / które mówił imieniem PAńſkim.
Tedy obejrzawƺy śię Ornán / ujrzał onego Anjołá ; á cżterej ſynowie jego którzy <i>byli</i> z nim ſkryli śię : á Ornán młóćił pƺenicę.
W tym przyƺedł Dawid do Ornáná / á pojrzawƺy Ornán obacżył Dawidá / y wyƺedƺy z bojewiſká pokłonił śię Dawidowi twarzą do źiemie.
Y rzekł Dawid do Ornáná : Daj mi plác <i>tego</i> bojewiſká / ábym zbudował ná nim Ołtarz PANU ; zá ſłuƺne pieniądze zpuść mi je / á będźie odwróconá tá plagá od ludu.
Y rzekł Ornán Dawidowi ; Weźmi <i>je</i> ſobie / á niech ucżyni Król Pán mój co mu śię dobrego widźi : Otoć przydawam y woły ná cáłopalenia / y wóz ná drwá / y pƺenicę ná ofiárę śniedną : <i>toć</i> wƺyſtko dawam.
Y rzekł Król Dawid do Ornáná : Nie ták : Ale rácżey kupię zá ſłuƺne pieniądze : Bo nie wezmę co twego jeſt : áni będę ofiárował PANU cáłopalenia dárowánego.
A ták Dawid dał Ornánowi zá <i>on</i> plác / ƺeść ſet ſyklów złotá dobrey wagi.
Y zbudował tám Dawid Ołtarz PANU : á ofiárował cáłopalenia y ofiáry ſpokojne : y wzywał PANA / który go wyſłuchał <i>spuśćiwƺy</i> ogień z Niebá ná Ołtarz cáłopalenia.
Y rzekł PAN do Anjołá / áby obróćił miecż ſwój w pochwy ſwoje.
Onego cżáſu widząc Dawid / iż go wyſłuchał PAN ná bojewiſku Ornáná Jebuzejcżyká / ofiárował tám ofiáry.
Abowiem Przybytek PAńſki / który ucżynił Mojzeƺ ná puƺcży / y Ołtarz cáłopalenia / ná on cżás <i>był</i> ná wyżynie w Gábáonie.
A nie mógł Dawid iść do niego / áby śię rádźił Bogá : bo przeſtráƺony był miecżem Anjołá PAńſkiego.
