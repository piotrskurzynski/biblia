A gdy ſobie pobudował Dawid domy w mieśćie ſwojim / y nágotował miejſce Skrzyni Bożey / y rozbił jey namiot :
Tedy rzekł Dawid : Nie <i>godźi śię</i> nośić Skrzynie Bożey jedno Lewitom : te bowiem obrał PAN / áby nośili Skrzynię Bożą / y ſłużyli mu / áż ná wieki.
Przetoż / zebrał Dawid wƺyſtkiego Izráelá do Jeruzalem / áby przenióſł Skrzynię PAńſką ná miejſce jey / które jey był zgotował.
Y zgromádźił Dawid Syny Aáronowe / y Lewity.
Z Synów Káátowych : Urielá przedniejƺego / y bráćij jego / ſto y dwádźieśćiá.
Z Synów Merárego : Aſájaƺá przedniejƺego / y bráćij jego / dwie śćie y dwádźieśćiá.
Z Synów Gerſonowych : Joelá przedniejƺego / y bráćij jego / ſto y trzydźieśći.
Z Synów Eliſáfánowych : Semejaƺá przedniejƺego / y bráćij jego / dwie śćie.
Z Synów Hebronowych : Elielá przedniejƺego / y bráćij jego / ośmdźieśiąt.
Z Synów Huſielowych : Aminádábá przedniejƺego / y bráćij jego / ſto y dwánaśćie.
Tedy wezwał Dawid Sádoká / y Abiátárá / Kápłanów : tákże Lewitów / Urielá / Aſájaƺá / y Joelá / Semejaƺá y Elielá y Aminádábá.
Y rzekł do nich : Wyśćie przedniejƺy z <i>domów</i> Ojcowſkich miedzy Lewitámi ; poświęććież śię y z bráćią ſwoją / ábyśćie przynieśli ſkrzynię PANA Bogá Izráelſkiego / ná miejſce / którem jey nágotował.
Abowiem iżeśćie tego pierwej nie ucżynili / ucżynił rozerwánie PAN Bóg náƺ miedzy námi : boſmy go nie ƺukáli według przyſtojnośći.
Poświęćili śię tedy Kápłani y Lewitowie / áby przenieśli ſkrzynię PANA Bogá Izráelſkiego.
Y nieśli Synowie Lewitów ſkrzynię Bożą / jáko był rozkazał Mojzeƺ / według ſłowá PAńſkiego / ná rámionách ſwych / ná drążkách / które przy niey były.
Y rzekł Dawid przedniejƺym z Lewitów / áby poſtánowili z bráćij ſwojey śpiewaki z inſtrumentámi muzyckimi / z lutniámi / z cytrámi / y z cymbałámi : áby ſłyƺány był wynieśiony głos z weſelem.
Y poſtánowili Lewitowie Hemáná Syná Joelowego / á z bráćij jego Aſáfá / Syná Báráchiaƺowego : á z Synów Merárego bráćij ich Etáná Syná Chuſájowego.
A z nimi bráćią ich <i>w rzędźie</i> wtórym : Zácháryaƺá / Bená / y Jázielá / y Semirámotá / y Jechielá / y Unni / Eliábá / y Benájaƺá / y Mááſejaƺá / y Mátytiaƺá / y Elifelego / y Miknejaƺá / y Obededomá / y Jehielá / odźwierne.
A śpiewacy : Hemán / Aſáf y Etán / ná cymbalech miedźiánych głośno gráli.
A Zácháryaƺ / y Jáziel / y Semirámot / y Jechiel / y Unni / y Eliáb / y Mááſejaƺ / y Benájaƺ / <i>gráli</i> ná lutniách przy śpiewániu wyſokim.
A Mátytiaƺ / y Elifele / y Miknejaƺ / y Obededom / y Jehiel / y Azázyaƺ / <i>gráli</i> ná cytrách przy śpiewániu niſkim.
A Kenániaƺ przedniejƺy z Lewitów którzy nieśli <i>Skrzynię</i> / rozrządzał jákoby nieść miano / bo był roſtropny.
Ale Báráchiáƺ / y Elkáná <i>byli</i> odźwiernymi u Skrzynie.
A Sebániaƺ / y Jozáfát / y Nátánáel / y Amáſáj / y Zácháryaƺ / y Benájaƺ / y Eliezer Kápłani / trąbili w trąby przed ſkrzynią Bożą : Ale Obededom / y Jechiaƺ / <i>byli</i> odźwiernymi u ſkrzynie.
A ták Dawid y Stárƺy Izráelſcy / y Hetmáni nád tyśiącámi / ƺli / áby przeprowádźili ſkrzynię przymierza PAńſkiego z domu Obededomowego z weſelem.
Y ſtáło śię / gdy Bóg wſpomógł Lewity / nioſące ſkrzynię przymierza PAńſkiego / że ofiárowáli śiedm wołów / y śiedm báránów.
A Dawid <i>był</i> oblecżony w ƺátę biśiorową : tákże y wƺyſcy Lewitowie którzy nieśli ſkrzynię / y śpiewacy / y Kenániaƺ / rządcá tych co nieśli miedzy śpiewaki : á Dawid miał ná ſobie Efod lniáne.
A ták wƺyſtek Izráel prowádźił ſkrzynię przymierza PAńſkiego z weſelem / y z hukiem kornetu / y trąby / y cymbałów : grájąc ná lutniách y ná Cytrách.
Y ſtáło śię / gdy ſkrzyniá przymierza PAńſkiego wchodźiłá do miáſtá Dawidowego / że Michol Córká Saulowá / wyglądájąc oknem / ujrzáłá Królá Dawidá ſkacżącego / y igrájącego : y wzgárdźiłá go w ſercu ſwojim.
