A ták Dawid będąc ſtáry y pełen dni / poſtánowił Królem Sálomoná Syná ſwego / nád Izráelem.
Y zgromádźił wƺyſtkie Kśiążętá Izráelſkie / y Kápłany / y Lewity.
A policżono Lewity / od trzydźieſtu lat y wyżey : y był pocżet ich według głów ich y oſób / trzydźieśći y ośm tyśięcy.
Z których poſtánowiono ná poſługę domu PAńſkiego / dwádźieśćiá y cżtery tyśiące : á Przełożonych y Sędźiów ƺeść tyśięcy.
Nád to cżtery tyśiące odźwiernych / y cżtery tyśiące chwalących PANA ná inſtrumenćiech / których náſprawiał <i>Dawid</i> ku chwaleniu <i>Bogá</i>.
Y rozdźielił ich Dawid ná <i>pewne</i> hufy / według Synów Lewiego ; <i>to jeſt</i> Gerſoná / Káátá / y Merárego.
Z Gerſoná <i>byli</i> Láádán y Semei.
Synowie Láádánowi przedniejƺy Jechiel / y Zetám / y Joel / <i>ći</i> trzej.
Synowie Semejowi : Sálomit / y Háziel / y Hárán / <i>ći</i> trzej : cić <i>byli</i> Przedniejƺy <i>domów</i> Ojcowſkich / z Láádáná.
A Synowie Semejowi : Jáchát / Zyná / y Jehus / y Báriaƺ : ćić Synowie Semejowi cżterej.
A Jáchát był pierwƺym / á Zyzá wtóry / ále Jehus y Báriaƺ / nie mieli wiele Synów : przetoż byli w domu Ojcowſkim policżeni zá jednę fámilią.
Synowie Káátowi / Amrám / Izáár / Hebron / y Huſiel / cżterej.
Synowie Amrámowi / Aáron / y Mojzeƺ. Lecż Aáron był odłącżony / áby ſłużył w Świątnicy naświętƺey / ſam / y Synowie jego / áż ná wieki : y áby kádźili przed PANEM / á ſłużyli mu / y błogoſłáwili w imieniu jego áż ná wieki.
Ale Synowie Mojzeƺá / mężá Bożego / policżeni ſą w pokoleniu Lewi.
Synowie Mojzeƺowi : Gerſon / y Eliezer.
Synowie Gerſonowi : Sebuel pierwƺy.
A Synowie Eliezerowi byli Rechábiaƺ pierwƺy. Y nie miał Eliezer Synów innych : Ale Synowie Rechábiaƺowi rozmnożyli śię bárzo.
Synowie Izáárowi / Sálomit pierwƺy.
Synowie Hebronowi / Jeryaƺ pierwƺy / Amáryaƺ wtóry / Jeháziel trzeći / á Jekmáán cżwárty.
Synowie Huſielowi / Michá pierwƺy / á Jeſyaƺ wtóry.
Synowie Merárego : Máheli / y Muſy. <i>A</i> Synowie Máhelego / Eleázár / y Cys.
Y umárł Eleázár / á nie miał Synów / tylko córki / które zpojmowáli Synowie Cyſowi / bráćia ich.
Synowie Muſy / Máheli / y Eder / y Jerimot / trzej.
Cić ſą Synowie Lewiego / według domów Ojców ſwych : przedniejƺy <i>domów</i> Ojcowſkich / którzy policżeni byli według pocżtu imion / y oſób ſwych z oſobná : którzy odpráwowáli prace uſługowánia / w domu PAńſkim / od dwudźieſtu lat y wyżey.
Abowiem rzekł Dawid : Dał odpocżynienie PAN Bóg Izráelſki ludowi ſwemu : y będźie mieƺkał w Jeruzalem áż ná wieki.
Do tego y Lewitowie nie będą więcey nośić przybytku / y wƺyſtkiego nacżynia jego / ku poſługowániu jego :
Ale według poſtánowienia Dawidowego oſtátniego / byli policżeni Synowie Lewiego / od dwudźieſtu lat y wyżey :
Aby zoſtawáli pod ręką Synów Aáronowych / ku uſłudze domu PAńſkiego / w przyśionkách y w gmáchách / y ku ocżyƺciániu wƺelkich rzecży poświęconych / y ku pracy około uſługi domu Bożego.
Y około chlebá pokłádnego / y około mąki ná ofiárę / y około plácków nie kwáƺonych / y około panewek / y około rzecży ſmáżonych / y około wƺelkiey miáry / y odmierzánia.
A yżby ſtali ná káżdy poránek ku wyſławiániu / y ku chwaleniu PANA / tákże y wiecżór.
Nád to / przy káżdym ofiárowániu cáłopalenia PANU / w Sábbáty / ná nowiu mieśiącá / y w urocżyſte świętá według licżby y porządku ich / uſtáwicżnie przed PANEM.
A ták áby pilnowáli ſtraży Namiotu zgromádzenia / y ſtraży świątnice / y ſtraży Synów Aáronowych bráći ſwych / w uſłudze domu PAńſkiego.
