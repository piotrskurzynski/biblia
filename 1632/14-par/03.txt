Pocżął tedy Sálomon budowáć dom PAńſki w Jeruzalem / ná górze Moria / która byłá ukazáná Dawidowi Ojcu jego : ná miejſcu / które zgotował Dawid / ná bojewiſku Ornáná Jebuzejcżyká.
A pocżął <i>go</i> budowáć mieśiącá wtórego / <i>dniá</i> wtórego / roku cżwartego króleſtwá ſwego.
Tenći jeſt pomiar Sálomonów / według którego budował dom Boży wdłuż łokći ƺeśćdźieśiąt / łokći podług miáry pierwƺey : wƺerz łokći dwádźieśćiá.
Przyśionek záśię / który był przed oną dłużą / y przed ƺerzą domu / był ná dwádźieśćiá łokći : á ná wzwyƺ ſto y dwádźieśćiá <i>łokći,</i> który obłożył wewnątrz ƺcżerym złotem.
A dom wielki okrył drzewem jodłowym / który też obił ƺcżerym złotem ; y dał po wierzchu nácżynić pálm y łáncuƺków.
Nákrył też dom kámieniem drogim ozdobnie / á złoto / <i>było</i> złoto Párwájmſkie.
Nád to / powlekł dom / bálki / podwoje / y śćiány jego / y drzwi jego złotem / á wyrył Cherubiny ná śćiánách.
Spráwił też dom Świątnice naświętƺey / którego dłuża <i>byłá</i> według ƺerokośći domu / ná dwádźieśćiá łokći / á ƺerza jego / ná dwádźieśćiá łokći : y powlekł go złotá ƺcżerego ƺeśćią ſet talentów.
Goźdźie też ważyły pięćdźieśiąt ſyklów złotá / tákże y Sálę powlekł złotem.
Spráwił też w domu Świątnice naświętƺey dwá Cherubiny robotą miſterną : y opráwił je złotem.
A ſkrzydłá Cherubinów <i>były</i> wdłuż ná dwádźieśćiá łokći : ſkrzydło jedno ná pięć łokći / á dośięgáło śćiány domu : drugie tákże ſkrzydło ná pięć łokći / dośięgáło ſkrzydłá Cherubiná drugiego.
Tákże ſkrzydło Cherubiná drugiego / ná pięć łokći / dośięgáło śćiány domu : á ſkrzydło drugie ná pięć łokći / ſkrzydłá Cherubiná drugiego.
<i>A ták</i> ſkrzydłá onych Cherubinów / rozƺerzone były ná dwádźieśćiá łokći ; á oni ſtali ná nogách ſwych / á twarzy ich <i>były</i> w dom <i>obrócone</i>.
Spráwił też zaſłonę z hyácintu / y z ƺárłatu / y z jedwabiu / y z ſubtelnego lnu : y dał wyháftowáć ná niey Cherubiny.
Ucżynił też przed domem dwá ſłupy / ná trzydźieśći y ná piąći łokći wzwyż : á gałká która <i>byłá</i> ná wierzchu ich / káżda byłá ná pięć łokći.
Spráwił też łáncuƺki / <i>jáko</i> w Świątnicy / á przypráwił <i>je</i> ná wierzch onych ſłupów : ſpráwił też ſto jábłek gránatowych / które wpráwił miedzy one łáncuƺki.
Y poſtáwił <i>one</i> ſłupy przed Kośćiołem : jeden po práwey / á drugi po lewey ſtronie : y názwał imię tego / co <i>był</i> ná práwey ſtronie / Jáchin ; á imię tego co <i>był</i> ná lewey ſtronie / Boáz.
