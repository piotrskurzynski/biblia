Y miał Jozáfát bogactw y ſławy bárzo wiele : á zpowinowáćił śię z Achábem.
Y przyjáchał <i>po kilku</i> lat do Achábá do Sámáryjey : y nábił Acháb owiec y wołów wiele dla niego / y dla ludu który <i>był</i> z nim ; y námawiał go áby ćiągnął do Rámot Gáláád.
Y rzekł Acháb Król Izráelſki do Jozáfátá Królá Judſkiego : Poćiągnieżże ze mną do Rámot Gáláád? A on mu odpowiedźiał : Jáko ja ták y ty ; á jáko lud twój / ták lud mój : y <i>będźiemy</i> z tobą ná wojnie.
Nád to rzekł Jozáfát do Królá Izráelſkiego ; Proƺę pytaj śię dźiś ſłowá PAńſkiego.
A ták zebrał Król Izráelſki proroków cżtery ſtá mężów / y rzekł do nich : Mamże ćiągnąć do Rámot Gáláád ná wojnę / cżyli zániecháć? A oni odpowiedźieli : Ciągni ; bo <i>je</i> da Bóg w ręce królewſkie.
Ale Jozáfát rzekł : Niemáƺże tu jeƺcże <i>którego</i> Proroká PAńſkiego / żebyſmy śię go pytáli.
Y rzekł Król Izráelſki do Jozáfátá ; <i>Jeſt</i> jeƺcże mąż jeden / przez któregobyſmy śię mogli rádźić PANA : ále go ja nienawidzę : bo mi nie prorokuje nic dobrego / ále záwżdy złe : á tenći jeſt Micheaƺ / Syn Jemlów. Y rzekł Jozáfát : Niech ták nie mówi Król.
Tedy záwołał Król Izráelſki niektórego komorniká / y rzekł : Przywiedź tu rychło Micheaƺá Syná Jemlowego.
Między tym Król Izráelſki / y Jozáfát Król Judſki śiedźieli káżdy z nich ná ſtolicy ſwojey / ubráni w ƺáty <i>królewſkie,</i> á śiedźieli ná plácu / u wrót bramy Sámáryjſkiey : á wƺyſcy Prorocy prorokowáli przed nimi.
A Sedechiaƺ Syn Chánáánów / ſpráwił ſobie rogi żelázne / y rzekł : Ták mówi PAN : Tymi będźieƺ bódł Syryjcżyki / áż je wyniƺcżyƺ.
Toż wƺyſcy Prorocy prorokowáli / mówiąc : Ciągni do Rámot Gáláád / á będźieć śię ƺcżęśćiło : ábowiem je poda PAN w ręce królewſkie.
Tedy poſeł który chodźił / áby przyzwał Micheaƺá / rzekł do niego / mówiąc : Oto ſłowá Proroków jednymi uſty dobrze tuƺą Królowi / niechże będźie / proƺę / ſłowo twoje jáko jednego z nich / á mów dobre <i>rzecży</i>.
Y rzekł Micheaƺ : Żywie PAN / że co mi kolwiek rozkaże Bóg mój / to mówić będę.
A gdy przyƺedł do Królá / rzekł Król do niego : Micheaƺu / mamyż ćiągnąć ná wojnę przećiw Rámot Gáláád / cżyli zániecháć? A on odpowiedźiał : Ciągnićie / á poƺcżęśći śię wam / y będą podáni w ręce wáƺe.
Y rzekł Król do niego : A wieleż ćię rázów mam przyśięgą obowięzowáć / ábyś mi nie mówił jedno práwdę w Imieniu PAńſkim?
Przetoż rzekł : Widźiałem wƺyſtek <i>lud</i> Izráelſki rozproƺony po górách jáko owce / które nie máją páſterzá. Bo PAN rzekł : Nie máją ći PANA : niech śię wróći káżdy do domu ſwego w pokoju.
Y rzekł Król Izráelſki do Jozáfátá : Yzażemći nie powiádał / że mi nic dobrego prorokowáć nie miał / ále złe?
Ale on rzekł : Słuchajćież tedy ſłowá PAńſkiego : Widźiałem PANA śiedzącego ná ſtolicy jego / y wƺyſtko wojſko niebieſkie ſtojące po práwicy jego / y po lewicy jego.
Y rzekł PAN : Kto zwiedźie Achábá Królá Izráelſkiego / áby ƺedł / á poległ w Rámot Gáláád? A gdy mówił jeden ták / á drugi mówił inák :
Wyſtąpił Duch / y ſtánął przed PANEM / y rzekł : Ja go zwiodę. A PAN mu rzekł : Przez cóż?
Y odpowiedźiał : Wynidę / á będę kłamliwym Duchem w uściech wƺyſtkich Proroków jego. Y rzekł <i>PAN</i> : Zwiedźieƺ / y pewnie przemożeƺ : Idźże / á ucżyń ták.
Przetoż teraz oto / dał PAN Duchá kłamliwego w uſtá tych Proroków twojich : gdyż PAN wyrzekł przećiwko tobie złe.
Tedy przyſtąpiwƺy Sedechiaƺ / Syn Chánáánów / uderzył Micheaƺá w policżek / mówiąc : A którąż drogą odƺedł Duch PAńſki ode mnie / áby mówił z tobą?
Y odpowiedźiał Micheaƺ : Oto ty ujrzyƺ dniá onego / kiedy wnidźieƺ do naſkrytƺey komory / ábyś śię ſkrył.
Y rzekł Król Izráelſki : Weźmićie Micheaƺá / á odwiedźćie go do Amoná / Stároſty miejſkiego / y do Joázá Syná Królewſkiego.
Y rzecżećie <i>im</i> : Ták mówi Król : Wſadźćie tego <i>do</i> więźienia / á dawajćie mu jeść chleb utrapienia / y wodę ućiſku / áż śię wrócę w pokoju.
Ale odpowiedźiał Micheaƺ : Jeſliże śię wróćiƺ w pokoju / <i>tedy</i> nie mówił PAN przez mię. Nád to rzekł : Słuchajćież wƺyſcy ludźie.
A ták ćiągnął Król Izráelſki / y Jozáfát Król Judſki / do Rámot Gáláád.
Y rzekł Król Izráelſki do Jozáfátá : Odmienię śię / á pójdę do bitwy : Ale ty ubierzeƺ śię w ƺáty ſwe. Y odmienił śię Król Izráelſki : á ƺli do bitwy.
A Król Syryjſki rozkazał był Hetmánom / którzy byli nád wozámi jego / mówiąc : Nie potykajćie śię áni z máłym / áni z wielkim / tylko z ſámym Królem Izráelſkim.
A gdy ujrzeli Jozáfátá Hetmáni / <i>co byli</i> nád wozámi / rzekli : Król Izráelſki jeſt. Y obróćili śię przećiw niemu / áby śię <i>z nim</i> potykáli : Ale záwołał Jozáfát / á PAN go rátował : y odwróćił je Bóg od niego.
Bo obacżywƺy Hetmáni <i>co byli</i> nád wozámi / że nie ten był Król Izráelſki / odwróćili śię od niego.
Lecż <i>niektóry</i> mąż ſtrzelił ná niepewną z łuku / y poſtrzelił Królá Izráelſkiego / miedzy nity / y miedzy páncerz : który rzekł woźnicy <i>ſwemu</i> : Náwróć á wywieź mię z wojſká / bom jeſt rániony.
Y wzmogłá śię bitwá dniá onego / á Król Izráelſki ſtał ná woźie przećiw Syryjcżykom / áż do wiecżorá : y umárł gdy záchodźiło ſłońce.
