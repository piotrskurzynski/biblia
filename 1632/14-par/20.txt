Y ſtáło śię potym / że przyćiągnęli Synowie Moábowi / y Synowie Ammonowi / á z nimi niektórzy <i>mieƺkający</i> zá Ammonitámi / przećiwko Jozáfátowi ná wojnę.
Y przyƺło / á opowiedźiano Jozáfátowi / mówiąc : Przyćiągnęło przećiwko tobie wojſko wielkie z zamorzá / z Syryjey / á oto ſą w Cháſeſontámár / które <i>jeſt</i> Engáddi.
Y ulękł śię / á obróćił Jozáfát twarz ſwoję / áby ƺukał PANA / y zápowiedźiał poſt wƺyſtkiemu <i>ludowi</i> Judſkiemu.
Tedy śię zgromádźił lud Judſki / áby ƺukáli PANA : tákże ze wƺyſtkich miaſt Judſkich zeƺli śię ƺukáć PANA.
A ták ſtánął Jozáfát w zgromádzeniu Judſkim y Jeruzalemſkim w domu PAńſkim / przed śienią nową.
Y rzekł : PANIE Boże Ojców náƺych : Izaliś nie ty ſam Bogiem ná niebie? á nie ty pánujeƺ nád wƺyſtkimi króleſtwy narodów? ázaż nie w ręku twojich jeſt moc y śiłá : á niemáƺ ktoby śię mógł oſtać przed tobą.
Yzaliś nie ty / Boże náƺ / wypędźił obywátele tey źiemie / przed twarzą ludu twego Izráelſkiego / y podałeś ją naśieniu Abráhámá przyjaćielá twego ná wieki?
Y mieƺkáli w niey / y zbudowáli tobie w niey świątnicę / dla Imienia twego / mówiąc :
Jeſliby ná nas przyƺło złe / miecż pomſty / álbo powietrze / álbo głód : á ſtániemy przed tym domem / y przed oblicżem twojim / gdyż Imię twoje jeſt w domu tym / á záwołamy do ćiebie w ućiſkách náƺych / tedy wyſłuchaƺ / y wybáwiƺ.
Teraz tedy / oto Synowie Ammonowi / y Moábowi / y górá Seir / przez któreś ty nie dopuśćił przejść Izráelowi / gdy ƺli z źiemie Egipſkiey / ále ich minęli / á nie wytráćili ich.
Oto teraz nam oni oddáwáją / gdyż przyƺli / áby nas wyrzućili z dźiedźictwá twego / któreś nam dał práwem dźiedźicżnym.
O Boże náƺ / izali ich nie będźieƺ ſądźił? W naſći záijſte nie máƺ żadney mocy przećiw mnóſtwu ták wielkiemu / które przyƺło ná nas : y nie wiemy co cżynić mamy / tylko ku tobie <i>obracamy</i> ocży náƺe.
Wƺyſtek też lud Judſki ſtał przed PANEM / y dźiatki ich / żony ich / y Synowie ich.
Ale Jeháziel / Syn Zácháryaƺá / Syná Benájaƺowego / Syná Jehielowego / Syná Mátániaƺowego / Lewitá / z Synów Aſáfowych : ná którego przyƺedł Duch PAńſki w pośrzód onego zgromádzenia :
Rzekł ; Słuchajćie wƺyſcy z Judy / y obywátele Jeruzalemſcy / y ty Królu Jozáfáćie : Ták wam powiáda PAN : Niebójćie śię wy / áni śię lękajćie tego mnóſtwá <i>ták</i> wielkiego : nie wáƺá <i>jeſt</i> walká / ále Boża.
Jutro śię ruƺćie przećiwko nim : oto oni pójdą ſtroną <i>góry</i> Sys / y znajdźiećie je ná końcu potoká / przećiw puƺcży Jeruel.
Nie wy śię potykáć będźiećie w tey <i>bitwie</i> ; ſtawćie śię / y ſtójćie / á oglądajćie wybáwienie PAńſkie nád wámi / o Judo y Jeruzalemie! Niebójćież śię / áni śię lękajćie ; jutro wynidźiećie przećiwko nim / á PAN <i>będźie</i> z wámi.
Y pokłonił śię Jozáfát twarzą ku źiemi / á wƺyſtek lud Judſki / y obywátele Jeruzalemſcy / pádli przed oblicżem PAńſkim / kłaniájąc śię PANU.
Wſtáli też Lewitowie z Synów Káátowych / y z Synów Korego / y chwálili PANA Bogá Izráelſkiego głoſem wielkim y wynioſłym.
Potym wſtawƺy ráno / ćiągnęli ná puƺcżą Tekuá ; á gdy wychodźili / ſtánął Jozáfát : y rzekł ; Słuchajćie mię Judo / y obywátele Jeruzalemſcy : wierzćie PANU Bogu wáƺemu / á będźiećie beſpiecżni : wierzćieƺ Prorokom jego / á będźie śię wam ƺcżęśćiło.
A wƺedƺy w rádę z ludem / poſtánowił śpiewaki PANU / którzyby <i>go</i> chwalili w ozdobie świętobliwośći / idąc przed uƺykowánymi do bitwy / y mówiąc : Wyſławiajćie PANA / ábowiė ná wieki miłośierdźie jego.
A w ten cżás / gdy oni zácżęli śpiewánie y chwały / obróćił PAN záſadzkę ná Syny Ammonowe / y Moábowe / y ná <i>obywátele</i> góry Seir / która byłá przyƺłá przećiw Judźie : y bili śię <i>ſami</i>.
Bo powſtáli Synowie Ammonowi y Moábowi / przećiwko obywátelom góry Seir / áby je pobili y wygłádźili. A gdy już do końcá <i>poráźili</i> one co mieƺkáli w Seir / oburzył śię jeden przećiw drugiemu / áż śię ſpólnie wybili.
A wtym <i>lud</i> Judſki przyƺedł do Máſfá / bliſko puƺcży : y pojrzawƺy ná ono mnóſtwo / <i>widźieli</i> á ono trupy leżáły po źiemi / ták yż nikt nie uƺedł.
Przetoż przyƺedł Jozáfát y lud jego / áby rozchwyćili łupy ich : y ználeźli przy nich bárzo wiele bogactw / y ná trupách klenotów koƺtownych / których rozchwyćili miedzy śię ták <i>wiele,</i> że ich zánieść nie mogli : przez trzy dni bráli one łupy / ábowiem ich <i>było</i> bárzo wiele.
Potym dniá cżwartego zebráli śię w dolinie Beráchá : bo yż tám błogoſłáwili PANA / przetoż názwáli imię miejſcá onego doliną Beráchá / áż do dźiśiejƺego dniá.
Zátym obróćili śię wƺyſcy mężowie Judſcy / y Jeruzalemſcy / y Jozáfát przed nimi / áby śię wróćili do Jeruzalė z rádośćią : ábowiem ućieƺył je był PAN / nád nieprzyjaćioły ich.
Y wjácháli do Jeruzalem / z hárfámi / y z cytrámi / y z trąbámi do domu PAńſkiego.
Tedy przypadł ſtrách Boży ná wƺyſtkie króleſtwá źiemie / gdy uſłyƺeli / yż PAN walcżył przećiw nieprzyjaćiołom ludu Izráelſkiego.
A ták uſpokojiło śię króleſtwo Jozáfátowe : Bo mu dał odpocżnienie Bóg jego zewƺąd.
Y królował Jozáfát nád Judą : <i>A</i> miał trzydźieśći y pięć lat / gdy królowáć pocżął : á dwádźieśćiá y pięć lat królował w Jeruzalem : á imię mátki jego <i>było</i> Azubá / córká Sálájowá.
A chodźił drogą Ojcá ſwego Azy : y nie uchylał śię od niey / cżyniąc co było dobrego w ocżách PAńſkich.
Wƺákże wyżyny nie były znieśione / bo jeƺcże lud niezgotował był ſercá ſwego ku Bogu Ojców ſwojich.
A oſtátek ſpraw Jozáfátowych pierwƺych y poślednich / jeſt zápiſány w Kśięgach Jehu / Syná Hánániego / któremu było rozkazano / áby <i>to</i> włożył w Kśięgi Królów Izráelſkich.
Potym ztowárzyƺył śię Jozáfát Król Judſki / z Ochoziaƺem Królem Izráelſkim / którego ſpráwy były bárzo niepobożne.
A ztowárzyƺył śię z nim ná to / áby nábudowáli okrętów / któreby chodźiły do Tárſys : y budowáli <i>one</i> okręty w Aſiongáber.
Przetoż prorokował Eliezer / Syn Dodáwáhów z Máreſy / przećiw Jozáfátowi / mówiąc : Yżeś śię ztowárzyƺył z Ochoziaƺem / rozerwał PAN ſpráwy twoje / y porozbijáły śię okręty / y niemogły iść do Tárſys.
