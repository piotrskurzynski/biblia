A ták dokońcżona jeſt wƺyſtká robotá / którą ſpráwił Sálomon do domu PAńſkiego : y wnióſł tám Sálomon rzecży / które był poświęćił Dawid Oćiec jego : śrebro / y złoto / y wƺyſtkie nacżynia włożył do ſkárbów domu Bożego.
Tedy zebrał Sálomon Stárƺe z Izráelá / y wƺyſtkie Przedniejƺe z káżdego Pokolenia / y przedniejƺe z Ojców Synów Izráelſkich / do Jeruzalem : áby przenieśli Skrzynię Przymierza PAńſkiego z miáſtá Dawidowego / które jeſt Syon.
Y zebráli śię do Królá wƺyſcy mężowie Izráelſcy / w święto urocżyſte / które <i>bywa</i> mieśiącá śiódmego.
A gdy śię zeƺli wƺyſcy Stárƺy z Izráelá / wźięli Lewitowie Skrzynię.
Y nieśli ſkrzynię / y Namiot zgromádzenia / y wƺyſtkie nacżynia święte / które <i>były</i> w Namiećie : przenieśli je Kápłani <i>y</i> Lewitowie.
Zátym Król Sálomon / y wƺyſtko zgromádzenie Izráelſkie / co śię byli zeƺli do niego przed ſkrzynię : Ofiárowáli owce / y woły których nie możno oblicżyć / áni obráchowáć przez mnóſtwo.
Wnieśli tedy Kápłani ſkrzynię Przymierza PAńſkiego / ná miejſce jey / do wnętrznego domu / <i>to jeſt</i> do Świątnice naświętƺey / pod ſkrzydłá Cherubinów.
Abowiem Cherubinowie mieli rozćiągnione ſkrzydłá / nád miejſcem ſkrzynie : y okrywáli Cherubinowie ſkrzynię / y drążki jey z wierzchu.
Y powyćiągáli one drążki / ták / że końce ich było widáć z ſkrzynie ná przodku Świątnice : ále ich nie widáć było zewnątrz / y támże zoſtáły áż do dniá tego.
<i>A</i> nic nie było w ſkrzyni / tylko dwie Tablice / które tám był włożył Mojzeƺ ná Horebie / gdy ſtánowił <i>przymierze</i> PAN z Synámi Izráelſkimi po wyśćiu ich z Egiptu.
A gdy wychodźili Kápłani z Świątnice / ( bo wƺyſcy Kápłani ile ich było / poświęćili śię byli / á nie przeſtrzegáli porządków. )
Stali Lewitowie / śpiewácy / y wƺyſcy którzy byli <i>przy</i> Aſáfie Hemmánie / y Jedytunie / y Synowie ich / y bráćia ich / oblecżeni będąc w ƺáty biśiorowe / z cymbały / y z hárfámi / y z cytrámi / ſtali <i>mówię</i> ná wſchodniey ſtronie Ołtarzá : á przy nich kápłanów ſto y dwádźieśćiá / trąbiących w trąby.
Y ſtáło śię / gdy jednoſtájnie trąbili / y śpiewáli / y wydawáli jednáki głos / chwaląc y ſławiąc PANA ; y gdy podnośili głos ná trąbách / y ná cymbałách / y ná <i>innych</i> inſtrumentách muzyckich / y chwalili PANA / że dobry / że ná wieki miłośierdźie jego : tedy dom <i>on</i> nápełniony jeſt obłokiem ; <i>to jeſt</i> dom PAńſki.
Ták / yż śię nie mogli Kápłani oſtáć / y ſłużyć dla onego obłoku. Abowiem nápełniłá <i>byłá</i> chwałá PAńſka dom Boży.
