Roku ośmnaſtego Królá Jeroboámá / królował Abiaƺ nád Judą.
Trzy látá królował w Jeruzalem : á imię mátki jego <i>było</i> Michájá córká Urielowá z Gábáá. Y byłá wojná miedzy Abiaƺem / y miedzy Jeroboámem :
Przetoż Abiaƺ uƺykował wojſko ludźi bárzo walecżnych / cżtery kroć ſto tyśięcy mężów przebránych. Jeroboám tákże uƺykował śię przećiwko niemu / májąc ośm kroć ſto tyśięcy mężów przebránych / bárzo walecżnych.
Tedy ſtánął Abiaƺ ná wierzchu góry Semeron / która <i>byłá</i> miedzy górámi Efráimſkimi / y rzekł : Słuchajćie mię Jeroboámie y wƺyſtek Izráelu.
Izali wam nie <i>należy</i> wiedźieć / że PAN Bóg Izráelſki dał króleſtwo Dawidowi nád Izráelem ná wieki / onemu / y ſynom jego przymierzem trwáłym?
Lecż powſtał Jeroboám / ſyn Nábátów / ſługá Sálomoná / Syná Dawidowego / y ſtał śię odpornym Pánu ſwemu ;
Y zebráli śię do niego mężowie lekkomyślni / á ludźie niepobożni ; y zmocnili śię przećiw Roboámowi Synowi Sálomonowemu : á Roboám będąc dźiećięćiem / y ſercá lękliwego / nie mógł śię im mężnie oprzeć :
Zácżym wy śię teraz myślićie zmocnić przećiw króleſtwu PAńſkimu / które jeſt w rękách Synów Dawidowych : á jeſt was kupá wielka ; y <i>maćie</i> z ſobą ćielce złote / których wam nácżynił Jeroboám zá Bogi.
Yzażeśćie nie zárzućili Kápłanów PAńſkich / Synów Aáronowych y Lewitów? á pocżyniliśćie ſobie Kápłany / jáko <i>inni</i> narodowie źiemſcy? Ktokolwiek przychodźi áby poświęcone były ręce jego / z ćielcem młodym / y z śiedmią báránów / ſtawa śię Kápłanem tych którzy nie <i>ſą</i> Bogowie.
Ale my jeſteſmy PANA Bogá náƺego / y nie opuśćiliſmy go : á Kápłani / którzy ſłużą PANU / <i>ſą</i> Synowie Aáronowi / y Lewitowie / którzy pilnują urzędu ſwego :
Y ofiárują PANU cáłopalenia ná káżdy záránek / y ná káżdy wiecżór : y kádzą rzecżámi wonnymi / y pokładáją chleby / ná ſtole cżyſtym ; tákże świecżnik złoty / y lámpy jego <i>ſporządzáją</i> áby gorzáły ná káżdy wiecżór. A ták my ſtrzeżemy rozkazánia PANA Bogá náƺego : á wyśćie go opuśćili.
Przetoż oto z námi jeſt ná cżele Bóg / y Kápłani jego / y trąby głośne / áby brzmiáły przećiwko wam. Synowie Izráelſcy / niewalcżćież z PANEM / Bogiem Ojców wáƺych : bo śię wam nie powiedźie.
Między tym obwiódł záſadzkę Jeroboám / áby ná nie przypádli z tyłu : Y byli <i>jedni</i> w ocży Judźie / á drudzy ná záſadzce z tyłu ich.
Tedy ujrzawƺy <i>Synowie</i> Judſcy / że ná nie <i>náſtępowáłá</i> bitwá z przodku y z tyłu / wołáli do PANA / á Kápłani trąbili w trąby.
Ucżynili też okrzyk mężowie Judá : Y ſtáło śię w onym okrzyku mężów Judſkich / że Bóg poráźił Jeroboámá / y wƺyſtkiego Izráelá przed Abiaƺem y Judą.
Y ućiekáli Synowie Izráelſcy przed Judą : ále je podał Bóg w ręce ich.
Y poráźili je Abiaƺ y lud jego / porażką wielką : ták / iż legło pobitych z Izráelá / pięć kroć ſto tyśięcy mężów ná wybór.
Przetoż poniżeni ſą Synowie Izráelſcy ná on cżás : á zmocnili śię Synowie Judſcy : ponieważ ſpolegáli ná PANU / Bogu Ojców ſwych.
Y gonił Abiaƺ Jeroboámá / á odjął mu miáſtá Bethel y wśi jego ; y Jeſáná y wśi jego ; y Efron y wśi jego.
A nie mógł śię więcey pokrzepić Jeroboám zá dni Abiaƺowych : y uderzył go PAN że umárł.
Ale Abiaƺ zmocnił śię / y pojął ſobie żon cżternaśćie / y zpłodźił dwádźieśćiá y dwu Synów / y ƺeſnaśćie córek.
Ale inne ſpráwy Abiaƺowe / y poſtępki jego / y ſłowá jego / zápiſáne ſą w Kśięgach Proroká Jáddy.
