Tedy rzekł Sálomon : PAN powiedźiał / yż mieƺkáć miał we mgle.
A jam zbudował dom ná mieƺkánie tobie / o <i>PAnie :</i> y miejſce gdźiebyś miał mieƺkáć ná wieki.
A obróćiwƺy Król oblicże ſwe / błogoſłáwił wƺyſtkiemu zgromádzeniu Izráelſkiemu / ( á wƺyſtko zgromádzenie Izráelſkie ſtało )
Y rzekł : Błogoſłáwiony PAN Bóg Izráelſki / który mówił uſty ſwymi do Dawidá Ojcá mego / y wypełnił to ſkutecżnie / mówiąc :
Ode dniá któregom wywiódł lud mój z źiemie Egipſkiey / nie obrałem miáſtá ze wƺyſtkich pokoleń Izráelſkich / ku zbudowániu domu / gdźieby przebywáło Imię moje : ánim obrał mężá któryby był wodzem nád ludem moim Izráelſkim.
Alem obrał Jeruzalem / áby tám przebywáło Imię moje : obrałem też y Dawidá / áby był nád ludem moim Izráelſkim.
Poſtánowił był Dawid Oćiec mój w ſercu ſwym <i>zbudować</i> dom Imieniowi PANA Bogá Izráelſkiego.
Ale rzekł PAN do Dawidá Ojcá mego : Acżkolwiekeś był poſtánowił w ſercu ſwym / zbudowáć dom Imieniowi memu / <i>y</i> dobrześ ucżynił / żeś to umyślił w ſercu ſwym :
Wƺákże ty nie będźieƺ budował tego domu / ále Syn twój który wynidźie z biódr twych ; ten zbuduje dom Imieniowi memu.
A ták utwirdźił PAN ſłowo ſwoje / które był powiedźiał : Bom <i>ja</i> powſtał miáſto Dawidá Ojcá mego / á uśiadłem ná ſtolicy Izráelſkiey / jáko był powiedźiał PAN ; y zbudowałem ten dom Imieniowi PANA Bogá Izráelſkiego.
Támżem też poſtáwił ſkrzynię onę / w którey jeſt Przymierze PAńſkie / które ucżynił z Syny Izráelſkimi.
Tedy ſtánął <i>Sálomon</i> przed Ołtarzem PAńſkim / przed wƺyſtkim zgromádzeniem Izráelſkim / y wyćiągnął ręce ſwe.
Abowiem był ucżynił Sálomon ſtolec miedźiány / który poſtáwił w pośrzód śieni : ná pięć łokći wdłuż / á ná pięć łokći wƺerz / á ná trzy łokćie wzwyƺ : Y wſtąpił nań / á poklęknąwƺy ná koláná ſwoje przed wƺyſtkim zgromádzeniem Izráelſkim / wyćiągnął ręce ſwe ku niebu.
Y rzekł : PAnie Boże Izráelſki / niemáƺ tobie podobnego Bogá ná niebie y ná źiemi : który chowaƺ umowę y miłośierdźie nád ſługámi twymi / którzy chodzą przed tobą cáłym ſercem ſwym.
Któryś ſpełnił ſłudze twemu Dawidowi Ojcu memu coś powiedźiał : y coś mówił uſty twymi / toś ſkutecżnie wypełnił / jáko śię to dźiś pokázuje.
Przetoż teraz / o PAnie Boże Izráelſki / zpełń ſłudze twemu Dawidowi Ojcu memu / coś mu był powiedźiał / mówiąc : Nie będźie odjęty mąż <i>z narodu</i> twego przed twarzą moją / áby niemiał śiedźieć ná ſtolicy Izráelſkiey : jeſli tylko przeſtrzegáć będą Synowie twoji drogi ſwey / chodząc w zakonie mojim / jákoś <i>ty</i> chodźił przed oblicżnośćią moją.
Przetoż teraz o PAnie Boże Izráelſki / niech będźie utwirdzone ſłowo twoje / któreś mówił do ſługi twego Dawidá.
( Acżći wprawdźie / izali Bóg będźie mieƺkał z cżłowiekiem ná źiemi? Oto niebioſá / y niebá niebios niemogą ćię ogárnąć / jákoż dáleko mniey ten dom którym zbudował? )
A wejrzy ná modlitwę ſługi twego / y ná proźbę jego o PAnie Boże mój ; wyſłuchaj wołánie y modlitwę / którą śię modli ſługá twój przed tobą.
Aby były ocży twoje otworzone nád tym domem we dnie y w nocy / nád tym miejſcem / o któremeś powiedźiał / że tu przebywáć będźie Imię twoje : ábyś wyſłuchiwał modlitwę / którą śię będźie modlił ſługá twój / ná tym miejſcu.
Wyſłuchajże tedy proźbę ſługi twego / y ludu twego Izráelſkiego / którąć śię modlić będą ná tym miejſcu : ty wyſłuchaj z miejſcá mieƺkánia twego / z niebá : á wyſłuchawƺy / bądź miłośćiw.
Gdyby cżłowiek zgrzeƺył przećiwko bliźniemu ſwemu / á przywiodłby go do przyśięgi / ták / żeby przyśięgáć muśiał / á przyƺłáby przyśięgá oná przed Ołtarz twój w tym domu :
Ty wyſłuchaj z niebá / á rozeznaj y rozſądź ſługi twoje ; potępiájąc niezbożnego / á obracájąc drogę jego ná głowę jego ; y uſpráwiedliwiájąc ſpráwiedliwego / á oddawájąc mu według ſpráwiedliwośći jego.
Gdyby też był poráżony lud twój Izráelſki od nieprzyjaćielá / przeto / yż zgrzeƺyli przećiwko tobie / á náwróćiliby śię wyznawájąc Imię twoje / y modląc śię przepraƺáliby ćię w tym domu :
Ty wyſłuchaj z niebá ; á odpuść grzech ludowi twemu Izráelſkiemu / á przywróć je záśię do źiemie którąś im dał y Ojcom ich.
<i>Tákże</i> gdyby záwárte było niebo / y nie byłoby deƺcżu / przeto / że zgrzeƺyli tobie / á modliliby śię ná tym miejſcu wyznawájąc Imię twoje / y od grzechu ſwego odwróćiliby śię / gdybyś je utrapił :
Ty wyſłuchaj z niebá / á odpuść grzech ſług twojich / y ludu twego Izráelſkiego / náucżywƺy ich drogi práwey po którey chodźić máją / á daj deƺcż ná źiemię twoję / którąś dał ludowi twemu w dźiedźictwo.
Byłliby głód ná źiemi / byłliby mór / ſuƺa / y rdzá / ƺáráńcża y chrząƺcże : jeſliby go śćiſnął nieprzyjaćiel jego w źiemi mieƺkánia jego / álbo jákakolwiek plagá / álbo jákakolwiek niemoc :
Wƺelką modlitwę / y wƺelką proźbę / którąby cżynił którykolwiek cżłowiek / álbo wƺyſtek lud twój Izráelſki / poznawƺy káżdy z nich karánie ſwoje y boleść ſwoję / y podnioſłby ręce ſwe w tym domu :
Ty wyſłuchaj z niebá z miejſcá mieƺkánia twego ; á odpuść / y oddaj káżdemu według wƺyſtkich dróg jego / które znaƺ w ſercu jego : ( bo ty / ty ſam znaƺ ſercá ſynów ludzkich )
Aby śię ćiebie bali / y chodźili drogámi twymi / po wƺyſtkie dni / których żyć będą ná źiemi / którąś dał Ojcom náƺym.
Nád to y cudzoźiemiec / który nie jeſt z ludu twego Izráelſkiego / y ten / przyjdźieli z źiemie dálekiey dla Imienia twego wielkiego / y ręki twojey możney / y <i>dla</i> rámienia twego wyćiągnionego / przydąli / á modlić śię będą w tym domu :
Ty wyſłuchaj z niebá / z miejſcá mieƺkánia twego / y ucżyń to wƺyſtko / o co záwoła do ćiebie on cudzoźiemiec / áby poználi wƺyſcy narodowie źiemſcy Imię twoje / y bali śię ćiebie jáko lud twój Izráelſki ; y wiedźieli że Imię twoje wzywáne jeſt nád domem tym / którym zbudował.
Gdyby wyƺedł lud twój ná wojnę przećiwko nieprzyjaćiołom ſwojim drogą którąbyś je poſłał / y modlilićby śię / obróćiwƺy śię ku temu miáſtu / któreś obrał / y ku domowi / którym zbudował Imieniowi twemu :
Wyſłuchajże z niebá modlitwy ich / y proźbę ich / á wykonaj ſąd ich.
Gdyby zgrzeƺyli <i>przećiwko</i> tobie / ( bo niemáƺ cżłowieká coby nie grzeƺył ) á rozgniewawƺy śię ná nie podałbyś je pod moc nieprzyjaćielowi / któryby ich pojimawƺy / záwiódł je w niewolą do źiemie dálekiey / álbo bliſkiey :
A upámiętáliby śię w ſercu ſwojim w oney źiemi / do którey ſą záprowádzeni w niewolą / á náwróćiwƺy śię / modliliby śię w źiemi niewoli ſwojey / mówiąc : Zgrzeƺyliſmy / źleſmy ucżynili / y niepobożnieſmy śię ſpráwowáli :
A náwróćiliby śię do ćiebie z cáłego ſercá ſwego / y z cáłey duƺe ſwey w źiemi niewoli ſwojey / do którey <i>będąc</i> pojimáni / záprowádzeni byli / á modliliby śię obróćiwƺy śię ku źiemi ſwey / którąś dał Ojcom ich / y ku miáſtu któreś obrał / y ku domowi którym zbudował Imieniowi twemu :
Wyſłuchajże z niebá / z miejſcá mieƺkánia twego modlitwę ich / y proźbę ich / á wykonaj ſąd ich / y odpuść ludowi twemu / który tobie zgrzeƺył.
A <i>ták</i> teraz / o Boże / proƺę niech będą ocży twoje otworzone / y uƺy twoje nákłonione / ku modlitwie <i>ucżynioney</i> ná tym miejſcu.
Teraz tedy / powſtań o PANIE Boże / ku odpocżnieniu twemu / ty / y ſkrzyniá mocy twojey : Kápłani twoji o PANIE Boże / niech będą oblecżeni zbáwieniem / á święći twoji niechaj śię w dobrách rádują.
O PANIE Boże / nie odwracaj oblicża Pomázáńcá twego : pámiętaj ná miłośierdźia <i>obiecáne</i> Dawidowi ſłudze twemu.
