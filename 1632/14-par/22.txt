Tedy poſtánowili Królem obywátele Jeruzalemſcy / Ochoziaƺá Syná jego namłodƺego / miáſto niego : Bo wƺyſtkie ſtárƺe pobiłá byłá kupá ſwawolna / która byłá przyƺłá z Arábcżykámi do obozu : á ták królował Ochoziaƺ Syn Jorámá Królá Judſkiego.
Cżterdźieśći y dwie lećie <i>było</i> Ochoziaƺowi / gdy <i>pocżął</i> królowáć ; á jeden rok królował w Jeruzalem. A imię mátki jego <i>było</i> Atália / córká Amrego.
Ten też chodźił drogámi domu Achábowego : bo mátká jego rádźiłá mu / áby śię niepobożnie ſpráwował.
Przetoż cżynił złe przed ocżymá PAńſkimi / jáko dom Achábów : te bowiem miał zá rajce ſwoje / po śmierći Ojcá ſwego / ná zginienie ſwoje.
Bo według rády ich chodźił / y jáchał z Jorámem Synem Achábowym / Królem Izráelſkim ná wojnę / przećiw Házáelowi królowi Syryjſkiemu / do Rámot Gáláádſkiego / kędy zránili Syryjcżycy Jorámá.
A gdy śię wróćił áby śię lecżył w Jezreelu / ( ábowiem <i>miał</i> rány które mu zádano w Rámie / gdy śię potykał z Házáelem / królem Syryjſkim ) Tedy Azáriaƺ Syn Jorámá królá Judſkiego przyjáchał do Jezreelá / náwiedzáć niemocnego Jorámá Syná Achábowego / bo był chory.
A było to od Bogá ná upádek Ochoziaƺowi / że przyjáchał do Jorámá : Abowiem przyjáchawƺy / wyjáchał z Jorámem przećiw Jehu / Synowi Námſy : którego był pomázał PAN / áby wytráćił dom Achábów.
A gdy ſąd wykonywał Jehu nád domem Achábowym / ználazł <i>niektóre</i> Kśiążęta Judſkie / y ſyny bráćij Ochoziaƺowych / którzy ſłużyli Ochoziaƺowi / y pobił je.
Potym ƺukał Ochoziaƺá : y pojimáli go / ( gdy śię krył w Sámárejey ) á przywiódƺy go do Jehu / zábili go / y pogrzebli go / bo mówili : Synći to jeſt Jozáfátá / który ƺukał PANA cáłem ſercem ſwojim : á ták nie było <i>nikogo</i> w domu Ochoziaƺowym / któryby mógł otrzymáć króleſtwo.
Przetoż Atália / mátká Ochoziaƺowá / widząc że umárł Syn jey / wſtawƺy wytráćiłá wƺyſtko naśienie królewſkie z domu Judá.
Ale Joſábet / córká królewſka / wźięłá Joázá / Syná Ochoziaƺowego / y wykrádłá go z pośrzód Synów królewſkich / których zábijano / y zchowáłá go / y mámkę jego do gmáchu / gdźie były łożá / y ſkryłá go Joſábet córká Królá Jorámá / żoná Jojády Kápłaná / ( bo oná byłá śioſtrą Ochoziaƺową ) przed Atálią / áby go nie zábiłá.
Y był z nimi w domu Bożym / będąc ſkrytym przez ƺeść lat / których Atália królowáłá nád <i>tą</i> źiemią.
