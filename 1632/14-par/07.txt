A gdy dokońcżył Sálomon modlitwy / tedy ogień zſtąpił z niebá / y pożárł cáłopalenie / y <i>inne</i> ofiáry : á chwałá PAńſka nápełniłá on dom.
Y nie mogli Kápłani wniść do domu PAńſkiego / przeto / że chwałá PAńſka nápełniłá dom PAńſki.
Y wƺyſcy Synowie Izráelſcy / widząc gdy zſtępował ogień / y chwałá PAńſka ná dom / upádli twarzą ſwą ná źiemię / ná tło : á kłaniájąc śię / chwalili PANA / że dobry / że ná wieki miłośierdźie jego.
A Król y wƺyſtek lud ſpráwowáli ofiáry przed PANEM.
Tedy nábił Król Sálomon ná ofiáry wołów dwádźieśćiá y dwá tyśiące / á owiec ſto y dwádźieśćiá tyśięcy / gdy poświącáli dom Boży Król y wƺyſtek lud.
Ale Kápłani ſtali w rzędziech ſwych : Lewitowie tákże z inſtrumentámi muzyki PAńſkiey / które był ſpráwił Dawid Król / ku chwaleniu PANA ( że ná wieki miłośierdźie jego ) pieśnią Dawidową / którą im podał. <i>Inni</i> też Kápłani trąbili przećiwko nim / á wƺyſcy Izráelcżycy ſtali.
Nád to / poświęćił Sálomon pośrzodek śieni / która byłá przed domem PAńſkim : Bo tám ofiárował cáłopalenia / y tłuſtośći ſpokojnych ofiar / przeto / że ná Ołtarzu miedźiánym / który był ſpráwił Sálomon / nie mogły śię zmieśćić cáłopalenia / y ofiáry śniedne / y tłuſtośći.
Y obchodźił Sálomon onego cżáſu święto urocżyſte przez śiedm dni / y wƺyſtek Izráel z nim / zgromádzenie bárzo wielkie / od weśćia do Emát / áż do rzeki Egipſkiey.
Potym ucżynili dniá óſmego święto : ábowiem poświęcenie Ołtarzá ſpráwowáli przez śiedm dni / y święto urocżyſte <i>obchodźili</i> przez śiedm dni.
A dniá dwudźieſtego y trzećiego / mieśiącá śiódmego / rozpuśćił lud do przybytków ſwojich / weſelący śię / y ćieƺący śię w ſercu <i>ſwym,</i> z dobrodźiejſtwá które ucżynił PAN Dawidowi y Sálomonowi / y Izráelowi ludowi ſwemu.
A ták dokońcżył Sálomon domu PAńſkiego / y domu królewſkiego : á wƺyſtko co był umyślił w ſercu ſwym ucżynić w domu PAńſkim / y w domu ſwym / wykonał ƺcżęśliwie.
Potym ukazał śię PAN Sálomonowi w nocy / y rzekł do niego : Wyſłuchałem modlitwę twoję / y obrałem to miejſce ſobie zá dom <i>do</i> ofiáry.
Jeſli zámknę niebo / żeby nie było deƺcżu ; y jeſli rozkażę ƺáráńcży / áby pożárłá źiemię ; jeſli też poślę powietrze ná lud mój :
A jeſliby śię upokorzył lud mój / nád którym wzywano Imienia mego / á modliłby śię / y ƺukałby twarzy mojey / odwróćiwƺy śię od dróg ſwojich złych : tedy ja wyſłucham z niebá / y odpuƺcżę grzech ich / á uzdrowię źiemię ich.
Ocży też moje otworzone będą / á uƺy moje nákłonione ku modlitwie <i>ucżynioney</i> ná tym miejſcu.
Bom teraz obrał y poświęćił ten dom / áby tu przebywáło Imię moje áż ná wieki : y będą tu ocży moje / y ſerce moje po wƺyſtkie dni.
A ty będźieƺli chodźił przede mną / jáko chodźił Dawid Oćiec twój / á będźieƺ śię ſpráwował według wƺyſtkiego com ći przykazał / ſtrzegąc uſtaw mojich y ſądów mojich.
Tedy utwirdzę ſtolicę króleſtwá twego / jákom ucżynił umowę z Dawidem Ojcem twojim / mówiąc : Nie będźie odjęty z narodu twego mąż pánujący nád Izráelem.
Ale jeſli śię wy odwróćićie / á opuśćićie uſtáwy moje / y przykazánia moje którem wam podał / á odƺedƺy / będźiećie ſłużyli Bogom cudzym / y będźiećie śię im kłaniáli.
Tedy je wykorzenię z źiemie mojey / którąm im dał : á ten dom / którym poświęćił Imieniowi memu / odrzucę od oblicża mego / y podam go ná przypowieść / y ná baśń / miedzy wƺyſtkie narody.
Nád to y ten dom / który był ſławny / káżdemu mimo idącemu / będźie ná podźiw / y rzecże : Przecżże ták ucżynił PAN tey źiemi / y temu domowi?
Tedy odpowiedzą : Przeto / yż opuśćili PANA Bogá Ojców ſwojich / który je wywiodł z źiemie Egipſkiey ; á chwyćili śię Bogów cudzych / y kłaniáli śię im / y ſłużyli im : dla tegoż przywiodł ná nie to wƺyſtko złe.
